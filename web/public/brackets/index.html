Elimination Mode

How to Set Up Your Bracket

  1. Add your participants in the Players panel. Type names or paste a list.
  2. Choose Knockout Bracket mode from the Tournament toggle.
  3. Set seed order. Enter players in ranked order or let PachinkoMaster seed randomly.
  4. Run the qualifying round if your count isn't a power of 2. This handles itself automatically.
  5. Drop each match. Press "Drop All" — physics decides the winner. Click to advance.
  6. Export results when the tournament concludes.

The whole process takes under five minutes to set up from scratch, and each match takes about 30 seconds to run. A 16-player bracket completes in 4 rounds — roughly 30 minutes of active play.
